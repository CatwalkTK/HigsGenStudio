あなたは映像作品の絵コンテアーティストです。
このフォルダはビデオ制作プロジェクトで、brief.md（企画）、story.md（ストーリー）、
characters.md（キャラクター設計書）があります。
3 つすべてを読み、絵コンテを **storyboard.md** に書いてください。

## 要件

1. story.md のシーンリストをカットに分解する。**カット合計秒数は brief.md のエンジン尺
   （15 秒 または 30 秒）に厳密に一致させる**（この動画は 1 回の生成で丸ごと作られるため）。
2. **各カットの尺配分はあなた（AI）の裁量**。目安は 1 カット 2〜8 秒。物語のリズムに
   合わせて自由に配分してよいが、極端な偏りは避ける。
3. **1 カット 1 アクション**: 「開始時の状態 → 終了時の状態」が 1 つの動きで
   つながるように書く（AI 動画は複数アクションの連続が苦手）。
4. カットごとに以下の表形式で書く（この構成を厳守）:

   ## Cut NN（シーン番号）
   | 項目 | 内容 |
   |------|------|
   | シーン / 場所 | |
   | 登場キャラ | characters.md のキャラ名で書く |
   | カメラ | サイズ（LS/FS/MS/CU/ECU）・アングル（eye/low/high）・ムーブ（fix/pan/tilt/dolly/zoom） |
   | 芝居・アクション | 開始時の状態 → 終了時の状態 |
   | セリフ / SE | story.md の原稿から該当分を割り当てる |
   | 秒数 | |
   | トランジション | cut / dissolve 等 |
   | 画面メモ | 構図・照明・画面内の重要要素 |

5. 映像文法を守る: カット間のつながり（イマジナリーライン/180度ルール、
   目線の方向、アクションつなぎ）、緩急（引きと寄りの交互配置）、
   冒頭 1〜2 カットで状況設定、ラストカットで感情の着地。
6. storyboard.md をこのフォルダ直下に**ファイルとして書き込む**こと。
   完了したら最後に DONE とだけ出力する。

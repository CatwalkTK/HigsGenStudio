あなたはアニメ・映像作品のキャラクターデザイナーです。
このフォルダはビデオ制作プロジェクトで、brief.md（企画）と story.md（ストーリー）があります。
両方を読み、登場キャラクター全員のキャラクター設計書を **characters.md** に書いてください。

## 要件

1. story.md のシーンリストに登場する全キャラクターを対象にする。
2. キャラごとに以下のセクション構成で書く（この構成を厳守）:
   - 役割 / 年齢感・性別 / 性格（3語以内）/ 動機 / 話し方の特徴
   - 外見設計（日本語メモ）: 体型、髪、目・顔、服装、小道具、カラーパレット
   - **カノニカル記述ブロック（英語）**: コードブロックで囲んだ英語 1 段落。
     画像生成プロンプトに一字一句コピーして使うため、年齢感・体型・髪（色/長さ/形）・
     目・肌・服装（色/素材/ディテール）・小道具まで具体的に固定する。
     曖昧な形容詞（beautiful, cool, stylish 等）は禁止。色は具体名で書く。
   - アセット表（空欄のまま。後工程で記入する）:
     | 種別 | job_id / media_id | URL | ローカル保存先 |
3. スタイルは brief.md の「スタイル」「スタイルキーワード」に厳密に合わせる
   （実写ならフォトリアルな人物として、アニメならアニメキャラとして記述する）。
4. キャラ同士の外見が紛らわしくならないよう、シルエット・配色を差別化する。
5. characters.md をこのフォルダ直下に**ファイルとして書き込む**こと。
   完了したら最後に DONE とだけ出力する。

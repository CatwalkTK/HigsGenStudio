# 🎬 HIGSGEN Studio

**日本語** · [English](README.en.md) · [Français](README.fr.md)

一言のリクエストから、**キャラクターの一貫性を保ったストーリー動画**（アニメ・実写・3D）を制作する、
Claude Code + Codex CLI + Higgsfield MCP のマルチエージェント・パイプライン。
FinalCut 風のビデオ編集 UI と、AI の作業内容を可視化するパネルを備えています。

```
「20代女性の沖縄一人旅をセリフ入りでビデオ化して」
        ↓
企画 → ストーリー → キャラクター設計 → 絵コンテ → プロンプト → 生成 → 編集
        ↓
30秒のショートフィルム（キャラの外見が全ショットで一貫、セリフ音声つき）
```

---

## 特徴

- **役割分担されたマルチエージェント**: Claude が監督・脚本、Codex がキャラ設計・絵コンテ、
  Higgsfield が画像・動画生成を担当
- **キャラクターの一貫性**: 英語カノニカル記述ブロック + キャラシート画像の参照渡しで、
  全ショットで同じ顔・同じ衣装を維持
- **人間による承認ゲート**: キャラクターと絵コンテがユーザー承認されるまで、
  動画生成をフックで**物理的にブロック**
- **クレジットガード**: 生成前に必ず見積り。上限超過時はユーザー確認を必須化
- **完全な監査証跡**: 全生成ジョブの job_id・モデル・**プロンプト全文**・消費クレジットを記録
- **アニメも実写も**: アニメ / 実写（フォトリアル）/ 3D スタイライズドをブリーフで選択

## 役割分担

| 役割 | 担当 | やること |
|------|------|---------|
| 監督・脚本家・アニメーター指示 | **Claude Code** | 企画、ストーリー執筆、生成プロンプト作成、全体統括・検証 |
| キャラクターデザイナー・絵コンテアーティスト | **Codex CLI** | キャラクター設計書、絵コンテ（カット割り）の作成 |
| 生成エンジン | **Higgsfield MCP** | キャラシート画像、動画クリップ、BGM/ナレーションの生成 |

## 動画エンジン

動画は **1 回の生成で完成尺を 1 本**作ります（シングルジェネレーション方式）。
エンジンで尺が決まり、カットごとの尺配分は AI に一任します。

| エンジン | Higgsfield model | 尺 | 解像度 | 音声 | 目安コスト |
|---------|------------------|-----|--------|------|-----------|
| **Seedance 2.0** | `seedance_2_0` | 15 秒 | 〜4K | ネイティブ生成 | 約 67.5 cr |
| **Seedance 2.5** | `seedance_2_5` | 30 秒 | 〜720p | ネイティブ生成 | 約 195 cr |
| **MiniMax H3** | `minimax_h3` | 15 秒 | 2K | 別撮り合成 | 約 60 cr |
| **おまかせ** | 自動解決 | 15 秒 | — | セリフあり→Seedance 2.0 / なし→MiniMax H3 | 60〜67.5 cr |

**おまかせモード**は、セリフの有無でエンジンを自動選択します（セリフあり＝ネイティブ音声を
持つ Seedance 2.0、セリフなし＝2K 高精細で最安の MiniMax H3）。ストーリー執筆でセリフの
有無が変わった場合は、Claude が同じルールで再判定します。

## UI — HIGSGEN Studio

```bash
node ui/server.mjs   # → http://localhost:4649
```

FinalCut 風のノンリニア編集レイアウトです。

```
┌──────────────┬─────────────────────┬──────────────────┐
│ ライブラリ     │ プレビュー            │ AI アクティビティ  │
│              │                     │                  │
│ 完成動画       │  ▶ 選択した素材/      │ ・現在の作業状態    │
│ クリップ       │    ドキュメント/      │ ・ワークフロー図    │
│ キャラシート    │    生成履歴          │  （アニメーション） │
│ フレーム/音声   │                     │ ・承認ゲート       │
│ 各種ドキュメント │                     │ ・パイプライン実行  │
│              │                     │ ・AI 活動履歴      │
├──────────────┴─────────────────────┴──────────────────┤
│ タイムライン（絵コンテから自動構成）                       │
│ [Cut 1·4s][Cut 2·5s][Cut 3·5s][Cut 4·5s][Cut 5·6s]... │
│ V1 映像 / A1 セリフ / 音声ベッド                          │
└────────────────────────────────────────────────────────┘
```

### 左: ライブラリ
完成動画・クリップ・キャラシート・フレーム・音声・全ドキュメントをブラウズ。クリックでプレビュー表示。

### 中央: プレビュー
動画プレーヤー、画像ビューア、Markdown レンダリング、生成履歴の詳細（プロンプト全文つき）。

### 右: AI アクティビティ
- **現在の作業状態**（実行中はスピナー、承認待ちなら該当フェーズを表示）
- **ワークフロー図**: 完了＝緑チェック、承認待ち＝オレンジ脈動、進行中＝青脈動＋流れる接続線
- **承認ゲート**: キャラクター・絵コンテの承認/差し戻し（フィードバック入力つき）
- **パイプライン実行**: コスト目安、指示文コピー、ヘッドレス実行、ログ表示
- **AI 活動履歴**: 担当（Claude 🧠 / Codex 🤖 / Higgsfield ⚡）・消費クレジット・
  クリックでプロンプト全文を表示

### 下: タイムライン（編集機能つき）
絵コンテのカット割りから自動構成。クリップをクリックするとプレビューがそのカットに頭出しされ、
再生中のカットがハイライトされます。

| 機能 | 内容 |
|------|------|
| **尺度調整** | 0.5x〜2x のリタイム（映像・音声とも） |
| **クロップ** | 上下左右を % 指定で切り出し（元解像度に再スケール） |
| **トリム** | クリップの IN/OUT を 0.1 秒単位で調整 |
| **ミュート** | クリップ単位で消音 |
| **音声分離** | 本編の音声トラックを MP3 として抽出 |
| **書き出し** | 編集を ffmpeg で適用し `out/<slug>_edit.mp4` を生成 |

編集内容は `edits.json`（EDL）に保存され、クリップにバッジ（✂ ⏩1.5x 🔇）と
変化後の尺（`5s→3.3s`）が表示されます。

## パイプライン

```
ユーザーの依頼
   │
Phase 0  企画（Claude / UI）        → brief.md       エンジン(=尺)・スタイル・アスペクト比
Phase 1  ストーリー（Claude）        → story.md       ログライン・あらすじ・シーン構成
Phase 2  キャラクター（Codex→HF）    → characters.md  設計書 + キャラシート画像 ⟹ 【承認ゲート】
Phase 3  絵コンテ（Codex）           → storyboard.md  カット割り（合計＝エンジン尺）⟹ 【承認ゲート】
Phase 4  ショットプロンプト（Claude） → shotlist.md    マルチショットのマスタープロンプト 1 本
Phase 5  生成（Higgsfield MCP）      → assets/clips/  1 回生成（キャラシートを参照入力）
Phase 6  編集（タイムライン UI / ffmpeg）→ out/         音声合成・カット調整・QA
```

### 安全装置

| 仕組み | 内容 |
|--------|------|
| **承認ゲート** | 全キャラクター + 絵コンテが承認されるまで、PreToolUse フックが `generate_video` を exit 2 でブロック（`get_cost` の見積りだけは通過） |
| **クレジットガード** | 生成前に必ず `get_cost` で実測見積り。プロジェクト上限を超える場合はユーザー確認が必須 |
| **生成台帳** | `ledger.md`（人間可読）と `ledger.json`（UI 用・プロンプト全文）に全ジョブを記録 |
| **キャラ一貫性** | カノニカル記述ブロックを全プロンプトで一字一句再利用 + キャラシートを `image_references` で参照 |
| **検証の徹底** | 生成物は URL/ファイルを実際に確認してから完了報告 |

## セットアップ

### 必要なもの

- **Node.js 18+** — UI サーバー（外部依存パッケージなし）
- **Claude Code** — パイプラインの実行環境
- **Higgsfield MCP** — Claude Code に接続済みであること（クレジット残高が必要）
- **Codex CLI**（`codex`）— 任意。なくても動作（Claude が代行するフォールバックあり）
- **ffmpeg / ffprobe** — タイムライン編集・書き出し・音声分離に使用

### 起動

```bash
git clone https://github.com/CatwalkTK/HigsGenSutudio.git
cd HigsGenSutudio
node ui/server.mjs        # → http://localhost:4649
```

## 使い方

### 方法 1: UI から（推奨）

1. `node ui/server.mjs` で http://localhost:4649 を開く
2. 「＋新規」でプロジェクト作成（作りたい動画・エンジン・スタイル・セリフ有無を入力）
3. 表示される指示文をコピーして Claude Code に貼り付け → パイプラインが Phase 1 から走る
4. キャラクター・絵コンテが生成されたら UI で**承認**（または修正点を書いて差し戻し）
5. 全承認後、動画生成 → タイムラインで編集 → 書き出し

### 方法 2: Claude Code に直接依頼

このフォルダで Claude Code を起動し、作りたい動画を伝えるだけ:

```
猫の宇宙飛行士が月でラーメン屋を開くアニメを Seedance 2.5 で作って
```

`/higsgen` スキルが起動し、企画 → ストーリー → キャラクター → 絵コンテ → 生成 → 編集の順に進みます。

プロジェクトの雛形だけ作る場合:

```bash
scripts/new-project.sh <slug>
```
